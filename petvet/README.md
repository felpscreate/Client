# PetVet — site institucional

Landing page responsiva em HTML, CSS e JavaScript puro, preparada para publicação no GitHub Pages.

## Como visualizar
Abra `index.html` no navegador. Não precisa instalar dependências.

## Personalização antes de publicar
1. Troque o número `5500000000000` no script do `index.html` pelo WhatsApp real (código do país + DDD + número, só dígitos).
2. Edite endereço, horários, e-mail, serviços e depoimentos de exemplo.
3. Substitua as imagens de demonstração por fotos próprias da clínica, se desejar.

## Publicar no GitHub Pages
1. Crie um repositório chamado `petvet` no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
4. Aguarde a publicação. O endereço será parecido com `https://SEU-USUARIO.github.io/petvet/`.

## Referências de inspiração
O layout usa uma direção visual própria inspirada em padrões modernos de landing pages e microinterações vistos em [21st.dev](https://21st.dev/) e [React Bits](https://reactbits.dev/), com animações leves em CSS e Intersection Observer.
